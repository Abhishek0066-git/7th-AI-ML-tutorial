# 7th AI & ML Tutorial

A beginner-friendly collection of Python practice programs and mini-projects. This repository builds programming fundamentals step by step as a foundation for learning Artificial Intelligence and Machine Learning.

## What you'll find

The exercises in `python practice` are organized by day and cover:

| Day | Topics |
| --- | --- |
| 1 | Variables, input, operators, and conditions |
| 2 | Strings and basic input cleanup |
| 3 | Lists and list operations |
| 4 | Tuples and sets |
| 5 | Dictionaries |
| 6 | Loops, ranges, and number analysis |
| 7 | Functions |
| 8 | File handling |

There are also introductory Python files in the `python` and `python Code with harry` folders.

## Getting started

### Requirements

- Python 3

No third-party packages are required for the current exercises.

### Run a program

Open a terminal in the repository folder and run a script with Python. For example, on Windows:

```powershell
py "python practice\day 1\variables.py"
```

Or, if `python` is available on your PATH:

```powershell
python "python practice\day 1\variables.py"
```

Choose another `.py` file to run a different exercise. Some programs ask for input in the terminal.

## Learning path

Work through the day folders in order, run each program, and try changing the inputs or extending the exercises. The goal is to understand the concepts by practicing, not just to read the code.
